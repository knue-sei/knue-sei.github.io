# 작업 진행 로그 규약

이 폴더는 이 볼트(AI-IIMS)에서 진행된 **작업 내역 전반**을 시간순으로 기록하는 곳입니다.
직접 한 작업, 회의·결정사항은 물론 **AI에게 시켜서 한 작업**(Claude, GPT, Gemini 등)도 함께 남깁니다.
맥·윈도우 등 여러 기기·세션에서 동시에 작업이 진행될 수 있어, 폴더 하나로 히스토리를 모읍니다.

## 파일명 규칙

- `YYYY-MM-DD-HHMM.md` (예: `2026-07-04-1315.md`)
- 같은 시각에 여러 건이 겹치면 초 단위(`YYYY-MM-DD-HHMMSS.md`)까지 붙여도 됨.
- **1개 작업 단위(요청→처리) = 파일 1개**. 사람이 직접 기록해도 되고, AI 어시스턴트가 매 턴 자동으로 남겨도 됨.

## 로그 형식

```markdown
# YYYY-MM-DD HH:MM (KST)

## 작업내용
(무엇을 했는지 요약 — 사람이 직접 했든 AI에게 시켰든 동일하게 기록)

## 인공지능 활용 (해당 시)
- 회사: 예) Anthropic, OpenAI, Google 등
- 모델: 예) Claude Sonnet 5 / claude-sonnet-5, GPT-5, Gemini 등
- 도구/환경: 예) Claude Code (VSCode 확장), 웹 챗 등
- 요청사항: AI에게 요청한 내용
- 실행사항: AI가 실제로 수행한 작업 — 생성/수정한 파일, 실행한 명령 등
```

> AI 없이 순수하게 사람이 직접 한 작업이면 "인공지능 활용" 절은 생략 가능.

## 목적

- 프로젝트 진행 상황과 의사결정 근거를 시간순으로 남겨 협업자가 나중에 참고.
- 여러 AI 회사·모델을 함께 쓰는 프로젝트이므로, **어떤 모델이 무엇을 했는지** 추적.
