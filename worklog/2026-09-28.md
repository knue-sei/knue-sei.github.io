## GitHub Pages 관련 메모
- 이 사이트는 Node 서버(관리자 로그인·업로드)가 필요해서 GitHub Pages(정적 호스팅)에서는 관리자 기능이 동작하지 않음
- knue-sei.github.io를 쓰려면 GitHub 조직/계정 `knue-sei` + 저장소 `knue-sei.github.io`가 필요함
- 방안 (A) 정적 내보내기 vs (B) Render 유지 → 사용자가 (A) 선택
