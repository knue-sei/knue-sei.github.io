## 작업내용

### 1. 한국어·영문 두 가지 버전
- 주소: 한국어 `/...`, 영문 `/en/...`. 상단·하단에 `English` / `한국어` 전환 링크(같은 페이지의 다른 언어판으로 이동), `hreflang` 표시
- `lib/views.js`: 화면 문구를 `T.ko` / `T.en`으로 분리, 모든 화면 함수에 `lang` 인자 추가
  - 게시글은 `title_en`, `summary_en`, `body_en`, `volume_en`, 첨부 `label_en`, 사진 `name_en`이 있으면 영문판에 사용하고, 없으면 한글로 대체
  - 관리자 로그인 메뉴는 한국어판에만 표시
- `lib/pages.js` 추가: 공개 페이지 주소 목록·화면 정보를 로컬 서버와 정적 게시가 함께 사용 (중복 제거)
- `server.js`: 공개 페이지 라우트를 `pages.js`로 통합, 404도 언어별, 로컬 관리자 저장 항목에 영문 필드 추가
- `lib/admin-views.js`: 로컬 관리자 글쓰기에 제목·권호·한 줄 소개·본문 (영문) 칸 추가
- `cms/config.yml`: 웹 관리자에도 같은 영문 칸 추가 (모두 선택 입력)
- `lib/content.js`: 연구 분야 영문, 소속 영문, 논총 영문명(`journalEn`), 연구진 `nameEn`(빈 값) 추가
- 기존 글 6건에 영문 제목·소개 입력 (행사 3건 번역, 논총 권호 `Vol. 29, No. 1` 등)
- `public/css/style.css`: 언어 전환 버튼 스타일, 영문판 로고 글자 크기 조정

확인이 필요한 항목
