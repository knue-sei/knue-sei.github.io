# 한국교원대학교 과학교육연구소 홈페이지

- 사이트: https://knue-sei.github.io (영문판 `/en/`)
- 글 올리는 방법: **[홈페이지_사용안내.md](홈페이지_사용안내.md)**

글은 GitHub 웹사이트에서 `content/` 폴더에 파일을 추가·수정해 올립니다. main에 변경이 생기면 GitHub Actions가 사이트를 다시 만들어 1~2분 뒤 반영합니다.

## 공개 저장소 이용 시 주의 (교수님 필독)

현재 저장소는 **공개 상태**입니다. 저장소에 올린 글·파일과 수정 기록은 누구나 볼 수 있습니다.

- 글의 `공개: 아니오`는 **홈페이지 목록에서만 숨깁니다.** GitHub 저장소에서는 누구나 볼 수 있습니다.
- 개인정보, 학생 성적·연락처, 내부 회의자료, 공개 전 원고 등 외부 공개가 곤란한 내용은 올리지 마세요.
- 사진·문서도 공개 승인을 확인한 뒤 올려 주세요. 인물이 식별되는 사진은 당사자 동의를 확인해 주세요.
- 잘못 올린 파일을 지우거나 저장소를 비공개로 바꾸어도, 이미 공개된 수정 기록이나 다른 사람이 내려받은 사본까지 회수되지는 않습니다. 실수로 민감한 정보를 올렸다면 파일만 삭제하고 끝내지 말고 관리 담당자에게 즉시 알려 주세요.

홈페이지의 저장소 링크에 **공용 비밀번호를 설정할 수는 없습니다.** 저장소를 비공개로 바꾸면 GitHub 계정으로 로그인하고 접근 권한을 받은 사람만 저장소를 볼 수 있습니다. 다만 홈페이지는 별도로 공개되므로, 저장소를 비공개로 바꾸어도 홈페이지 내용까지 비공개가 되지는 않습니다.

## 저장소 비공개 전환 (관리 담당자)

현재 기관 정책상 저장소를 공개 상태로 운영합니다. 정책이 바뀌어 비공개 전환이 필요할 때는 다음을 확인해 주세요.

1. 기관의 GitHub 조직 관리자에게 비공개 저장소에서 GitHub Pages 배포를 계속 지원하는 요금제·정책인지 확인합니다. 지원되지 않으면 홈페이지 배포가 중단될 수 있습니다.
2. 저장소 관리 권한이 있는 계정으로 GitHub 저장소의 **Settings → General → Danger Zone → Change repository visibility**로 이동합니다.
3. **Make private**를 선택하고 GitHub의 확인 절차를 완료합니다. 이 작업은 저장소 관리자만 할 수 있습니다.
4. 전환 후 **Settings → Pages**와 **Actions**에서 배포 설정 및 최근 배포 성공 여부를 확인하고, 홈페이지 주소가 계속 열리는지도 확인합니다.

비공개 전환은 저장소 접근만 제한합니다. 홈페이지는 계속 공개될 수 있으며, 전환 전에 만들어진 공개 복제본이나 내려받은 사본도 자동으로 회수되지 않습니다.

## 구조

| 경로 | 내용 |
|---|---|
| `content/` | 게시글 (학술행사·간행물·소식, 글 1개 = `.md` 1개, 각 폴더의 `_양식.md` 참고) |
| `uploads/` | 글에 넣는 사진·PDF |
| `public/` | CSS·로고·최초 자료 |
| `lib/content.js` | 고정 문구: 연구 분야, 연구진, 영문 논총명 |
| `lib/views.js` | 화면 구성과 한국어·영어 문구 |

## 관리 담당자

- **글쓴이 추가**: 저장소 Settings → Collaborators → GitHub 사용자 이름으로 초대 (Write 권한)
- **게시 설정**: Settings → Pages → Source가 **GitHub Actions** 인지 확인
- **수정이 필요한 곳**
  - 연구진 영문 이름: `lib/content.js`의 `nameEn` (비어 있으면 영문판에 한글 이름 표시)
  - 논총 공식 영문명: `lib/content.js`의 `journalEn`
  - 사용 안내문 끝의 문의처: `홈페이지_사용안내.md`
